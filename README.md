# 🦷 Зубки малыша — Трекер прорезывания и гигиены зубок

Веб-приложение (PWA), специально оптимизированное для **iPhone (Safari iOS)**, созданное с любовью для мамы и малыша.

---

## 🌟 Возможности приложения

### 🪥 1. Трекер чистки зубов
- **Крупный статус-виджет**: отображает, когда чистили зубки последний раз (*«Сегодня в 09:15 — 2 часа назад»*), а также чек-листы на сегодня:
  - ☀️ Утренняя чистка
  - 🌙 Вечерняя чистка
- **Быстрая фиксация в 1 тап**: большая кнопка «Почистили зубки!» с возможностью указать заметку (например, *«с банановой пастой»*).
- **Интерактивный таймер чистки для ребенка (60 или 120 сек)**:
  - Анимированная зубная щеточка 🪥 и сверкающие звездочки ✨, которые развлекают малыша во время чистки.
  - Звуковые эффекты (Web Audio API) и победный салют конфетти по окончании.
- **Серия без пропусков (Streak)**: подсчет дней непрерывной гигиены (*«🔥 5 дней подряд»*) и недельный мини-календарь.

### 🦷 2. Зубная карта и дневник прорезывания
- **Анатомическая дуга (20 молочных зубов)**:
  - Верхняя челюсть (10 зубиков) и Нижняя челюсть (10 зубиков).
  - Понятные ориентиры: *«Правая щечка малыша»* и *«Левая щечка малыша»*.
- **3 статуса каждого зуба**:
  - ⚪ *Пока нет* (спит)
  - 🟡 *Режется* (десна набухла, пульсирует в приложении)
  - 🟢 *Вылез!* (прорезался, с зеленой галочкой)
- **Карточка зубика (шторка снизу в стиле iOS)**:
  - Подсказка нормы по возрасту (например, *«Центральный резец: обычно 6–10 месяцев»*).
  - Выбор точной даты выхода (кнопки «Сегодня», «Вчера» или выбор в календаре).
  - Быстрые теги симптомов: *«💧 Слюни рекой»*, *«🤒 Температура»*, *«🥺 Капризы»*, *«🧸 Грызет всё подряд»*, *«⚡ Отек десны»*, *«🧴 Мазали гелем»*.
  - Заметки родителей.
- **Хронология**: упорядоченный список прорезавшихся зубок с расчетом возраста малыша на момент каждого зубика (*«в 7 месяцев и 14 дней»*).

### 📱 3. Оптимизация под iPhone (iOS Safari PWA)
- Адаптация под безопасные зоны (Safe Area Insets для Dynamic Island и «челки»).
- Крупные кнопки под палец, защита от случайного приближения экрана (зума) в Safari.
- Установка на рабочий стол в виде автономного приложения (без рамок браузера).
- 100% оффлайн-работа благодаря Service Worker (работает даже в самолете или без связи).

### 🛡️ 4. Сохранность данных
- Хранение в памяти телефона (LocalStorage).
- Кнопка **«Скачать резервную копию (JSON)»** в 1 клик.
- Кнопка **«Скопировать в буфер»** (чтобы быстро отправить копию данных в Telegram/WhatsApp).
- Восстановление из файла в любое время.

## 🚀 Как развернуть бесплатно

### Вариант 1: GitHub Pages (Бесплатно навсегда)
1. Создайте новый публичный репозиторий на GitHub (например, `baby-teeth`).
2. Загрузите файлы этого проекта в репозиторий.
3. Откройте в репозитории: **Settings** ➔ **Pages**.
4. В разделе **Build and deployment** выберите Source: **Deploy from a branch** ➔ ветка `main` (или `master`) ➔ папка `/ (root)` ➔ нажмите **Save**.
5. Через 1 минуту сайт будет доступен по адресу:  
   `https://ВАШ_НИК.github.io/baby-teeth/`

### Вариант 2: Netlify Drop (Запуск за 10 секунд без Git)
1. Откройте сайт [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите папку с этим проектом в окно браузера.
3. Готово! Вы сразу получите постоянную бесплатную ссылку с HTTPS (например, `https://baby-teeth-misha.netlify.app`).

### Вариант 3: Vercel
1. Зайдите на [vercel.com](https://vercel.com), нажмите **Add New Project**.
2. Подключите ваш GitHub репозиторий и нажмите **Deploy**.

## 📲 Как маме установить на iPhone
1. Откройте полученную ссылку в браузере **Safari** на iPhone.
2. В нижней панели Safari нажмите кнопку **«Поделиться»** (значок квадрата со стрелкой вверх).
3. Прокрутите список вниз и нажмите **«На экран Домой»**.
4. Нажмите **«Добавить»** в верхнем правом углу.

На экране появится красивая иконка приложения 🦷, и оно будет открываться на весь экран без адресной строки!
